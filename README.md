# Crimson Cup Cafe

A modern, responsive website for Crimson Cup Cafe, showcasing our menu, ambiance, and services.

## Features

- Responsive design for all devices
- Interactive menu display
- Image gallery
- Contact information

## Installation

To get a local copy up and running, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/shopifyaryan/Crimson-cup-cafe.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Crimson-cup-cafe
   ```

3. Open `kaira.html` in your web browser to view the site.

## Usage

Simply open the `kaira.html` file in any modern web browser to explore the cafe's website.
